歡迎來到生成式 AI 工具的三大核心：技能 Skill、專案 Project 與 MCP。這三者像三塊拼圖，分別回答「怎麼做」、「在哪裡做」與「能連接什麼」。

總覽 · 三個比喻

從「會做什麼」到「在哪裡做」，再到「能連接什麼」

像一本標準作業手冊

  • 定義步驟、規則與輸出格式
  • 讓 AI 穩定完成特定任務
  • 適合反覆套用與分享

回答：怎麼做？

專案 Project集中管理工作的專屬空間

像一間有資料的工作室

  • 收納對話、檔案與背景脈絡
  • 維持長期任務的一致性
  • 適合課程、研究與團隊工作

回答：在哪裡做？

MCPAI 與外部服務的通用連接方式

像可插拔的萬用轉接器

  • 串接資料庫、雲端與各種工具
  • 讓 AI 查詢資料或執行動作
  • 權限與連線設定要妥善管理

回答：連接什麼？

先用比喻認識它們。Skill 像一本標準作業手冊，把做事方法封裝起來；Project 像一間有資料的工作室，收納對話、檔案與背景；MCP 像可插拔的萬用轉接器，讓 AI 連上外部服務。

技能是一套可被 AI 讀取的任務說明。把適用時機、操作步驟、參考資料與輸出格式封裝成一項技能，設定一次，就能穩定品質、節省重複說明，也方便分享給同事。

一個技能其實就是一個資料夾。核心是 SKILL 點 md 檔，寫清楚名稱與用途、觸發條件、操作步驟與輸出規格；再視需要附上參考資料、範本或程式腳本。重複任務、統一品質、分享方法，都是建立技能的好時機。

技能 Skill · 建立與使用

四個步驟，做出一個好技能

  1. 1定義任務對象、目標、輸入
  2. 2寫出步驟規則、範例、例外
  3. 3測試修正用真實題目檢查
  4. 4呼叫使用提供主題與素材
教學範例 輸入：AI 生成內容是否應標示？ 技能：探究教學設計 輸出：教案、學習任務、評量規準
好 Skill ＝ 清楚任務＋ 完整流程＋ 明確規範＋ 可驗證產出

建立技能有四個步驟：定義任務、寫出步驟、測試修正、呼叫使用。例如輸入「AI 生成內容是否應標示」，套用探究教學設計技能，就能產出教案、學習任務與評量規準。好技能要任務明確、步驟可操作、成果可驗證。

MCP 是 Model Context Protocol，模型情境協定，是 AI 應用與外部服務溝通的開放標準。使用者提出任務，AI 應用透過內建的 MCP 用戶端向 MCP 伺服器發出請求，伺服器再存取雲端檔案、資料庫或行事曆，把結果送回來。

MCP · 伺服器提供三類能力

工具、資源、提示：MCP 的三種能力

工具 Tools

查詢、計算或執行動作

例：搜尋檔案、建立行事曆活動

資源 Resources

讀取可用的內容與背景資料

例：教材文件、資料紀錄

提示 Prompts

提供可重用的任務範本

例：固定格式的分析提問

主要用途

取得資料搜尋文件與即時資訊
執行工具查詢、建立、更新內容
整合系統串接不同平台與服務
降低開發同一規格，重複使用

MCP 伺服器可提供三類能力：工具 Tools 用來查詢或執行操作；資源 Resources 提供可讀取的背景資料；提示 Prompts 提供可重用的任務範本。好處是取得資料、執行工具、整合系統，並以同一規格降低開發成本。

MCP · 使用流程與安全

六步驟使用 MCP，授權先想清楚

  1. 1選擇 MCP Server確認來源與用途
  2. 2連線並授權設定可存取範圍
  3. 3AI 發現能力列出可用工具
  4. 4提出需求AI 選用合適工具
  5. 5確認後執行重要操作先確認
  6. 6回傳結果核對資料與執行紀錄
高中教學範例 教師提問：整理圖書館新書清單並製作書展摘要 AI 應用MCP 服務讀取授權清單產出摘要
  • 只連接可信任來源
  • 採最小權限原則，只開啟必要權限
  • 修改、寫入或分享資料前，先檢查操作內容

使用流程是：選擇 MCP Server、連線並授權、讓 AI 發現可用能力、提出需求、確認後執行、回傳結果。例如請 AI 整理圖書館新書清單並製作書展摘要。使用前請記得：只連可信任來源、採最小權限、重要操作先確認。

在 Project 中管理任務，用 Skill 執行標準流程，再透過 MCP 取得資料與操作工具。先確認需求，再選擇工具。

三者如何協作？先建立 Project，設定目標與保存素材；再套用 Skill，依標準流程處理任務；需要外部資料時透過 MCP 取得；最後回到 Project 保存成果並持續改進。Project 管脈絡、Skill 管方法、MCP 管連接。
